# Hotstar Content Analysis Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Hotstar content dataset to understand content distribution, ratings, genres, runtime patterns, and platform trends.
The goal is to extract actionable insights that can help in content strategy, user engagement, and platform optimization.

## Business Objective
- Analyze Hotstar’s content library
- Identify popular content types and genres
- Understand rating and runtime distribution
- Provide insights useful for OTT business decisions

## Data Source 
The dataset used in this project contains information about movies and TV shows available on Hotstar,It includes details such as content type, genre, runtime, release year, and ratings.
- <a href="https://github.com/subhajitdas1800/Hotstar-Content-Analysis-Exploratory-Data-Analysis-EDA-/blob/main/hotstar.csv"> Hotstar(CSV)</a>
The dataset is provided in CSV format and is used only for learning and portfolio purposes.

## KPI Requirements 
The following KPIs were derived from the dataset:
- Total Content Count
- Movies vs TV Shows Distribution
- Average Runtime
- Most Common Genres
- Rating Distribution
- Year-wise Content Growth

## Charts & Visualizations
The notebook includes the following visual analyses:

📌 Content Type Distribution (Movies vs TV Shows)

📌 Runtime Distribution (Histogram / Boxplot)

📌 Rating Distribution

📌 Genre Frequency Analysis

📌 Release Year Trend Analysis

📌 Top Genres by Content Count

## Insights
- Movies dominate the Hotstar content library compared to TV shows
- Majority of content falls within a specific runtime range, indicating platform preference
- Certain genres (like Drama / Comedy) are significantly more frequent
- Content production has increased noticeably in recent years
- Ratings show clustering, suggesting standard content quality benchmarks
